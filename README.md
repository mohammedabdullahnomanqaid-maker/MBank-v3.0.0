# Project_MBank
MBank (Beta Version) 🏦 A C# .NET banking system using file-based storage. It features complex financial logic and treasury management, built in 10 days. ​Key Features: 🔹 Currency Calc: Real-time conversion for 56 countries. 🔹 Vault Logic: Centralized treasury linked to all transactions. 🔹 Security: Role-based access and a sleek Modern UI.
